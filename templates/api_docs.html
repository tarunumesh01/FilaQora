REST API

All API endpoints require a Bearer token.

Authorization: Bearer YOUR_API_TOKEN

GET /api/customers

List customers. Optional query parameters: q, page, per_page.

{
  "items": [],
  "page": 1,
  "pages": 1,
  "total": 0
}

GET /api/customers/<id>

Return one customer.

POST /api/customers

Create a customer.

{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "phone": "1234567890",
  "company": "Example Ltd",
  "tags": "lead,vip"
}

PUT /api/customers/<id>

Update any supplied customer fields.

DELETE /api/customers/<id>

Delete a customer. Returns HTTP 200 on success.
